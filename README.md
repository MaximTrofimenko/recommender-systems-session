# Сессионное задание: рекомендации книг

Ноутбук `sz.ipynb` продолжает домашнее задание `hw1`: использует те же данные Goodbooks-10k и модели Popularity, Item-Based CF и SVD. Дополнительно строятся признаки пользователей и книг, гибридная модель, анализ по группам пользователей и небольшой эксперимент с нейросетью MLP.

Данные лежат в папке `data` этого проекта. Запускайте ноутбук сверху вниз в PyCharm или Jupyter из папки `сессионное`. Зависимости перечислены в `requirements.txt`; для установки можно выполнить `pip install -r requirements.txt` в окружении проекта.

Оценка проводится на отложенных 20% взаимодействий. Релевантными считаются книги с оценкой от 4. Для подбора веса гибрида выделены отдельные пользователи, после чего модели сравниваются по Precision@5, Recall@5 и nDCG@5 на одной выборке. Результаты зависят от запуска и выводятся прямо в ноутбуке.
